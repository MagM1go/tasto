# О чём tasto?
Tasto — это моя попытка реализовать RFC9112 + смежные с ним. Попытка не пытка, как говорится.
Возможно, этот репозиторий будет вовсе сноситься подчистую и ядро логики будет переписываться с нуля

Примеры, чего я примерно хочу добиться, можете найти в папочке `examples/`, она где-то наверху.

TL;DR для тех, кто всё ещё не понял: HTTP/S клиент-сервер на собственной базе.

# В чём идея?
Идея проста: sans-IO ядро, отдельные sync и async транспорты, и "пользовательский" уровень в виде клиента. Всё это, кроме транспорта, можете найти в тех же примерах, что и выше.
